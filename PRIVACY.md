# OmniPilot Privacy Policy

**Effective date:** July 10, 2026

OmniPilot is an open-source browser extension that lets users send selected text, page content, and chat messages to AI providers and Agent-to-Agent (A2A) servers they choose or configure. This policy explains how OmniPilot processes data.

## Data OmniPilot Processes

Depending on the feature you invoke, OmniPilot may process:

- text you select on a webpage;
- prompts, chat messages, and conversation context you submit;
- full page content or GitHub issue and pull request content when you request a summary;
- responses returned by your configured AI provider or A2A server;
- provider configuration and credentials, including API keys and tokens;
- optional long-term notes and recent activity used by the memory feature; and
- diagnostic traces and guardrail audit records generated by the extension.

OmniPilot processes page content only to provide features you initiate. It does not sell personal information or use page content for advertising.

## Where Data Is Stored

Provider settings and credentials—including endpoint URLs, API keys, selected models, provider configurations, and preferences—are stored in browser sync storage and may be synchronized between browsers signed in to the same browser account. A2A server definitions and tokens use browser local storage when that storage area is available and can fall back to sync storage if local storage is unavailable. Legacy A2A server definitions may also be migrated from sync storage to local storage. Optional memory and activity logs, diagnostic traces, and guardrail audit records are stored in browser local storage.

The OmniPilot project does not operate a separate analytics or advertising service that collects extension data. However, the extension's default custom-provider endpoint is `https://api.omnillm.com/v1`. If you configure an API key and submit a request without changing that endpoint, the request content is transmitted to that OmniLLM endpoint. You can replace the endpoint in settings before submitting content.

## When Data Is Transmitted

When you submit an AI action, chat turn, page summary, or A2A delegation, OmniPilot sends the content needed for that request to the user-configured provider or A2A server. These services may include GitHub Copilot, Azure Foundry, a custom OpenAI- or Anthropic-compatible endpoint, or an A2A server you add.

Those third-party services process data under their own terms and privacy policies. Review the policies and retention settings of each service before using it. OmniPilot does not control how a provider or A2A server handles data after receiving a request.

GitHub Copilot authentication uses GitHub's device authorization flow. Authentication requests and tokens are exchanged with GitHub services as needed to sign in and access Copilot.

## User Choices and Data Deletion

You choose which provider and A2A servers to configure and which content to submit. You can edit or clear memory, recent activity, and diagnostic information from the extension settings where those controls are available. You can remove stored settings and credentials by clearing the extension's site data or uninstalling OmniPilot.

Provider-side copies must be managed through the applicable provider or A2A server because OmniPilot cannot delete data retained by third parties.

## Data Retention

Local and synchronized settings and credentials remain until you change them, clear the extension's data, disable browser synchronization where applicable, or uninstall the extension. Optional activity logs and diagnostic records use the extension's configured rolling or bounded retention behavior and may also be cleared from settings. Third-party retention is governed by the service receiving the request.

## Security

OmniPilot relies on browser extension storage and transport security provided by the browser and configured services. No system can guarantee absolute security. Users are responsible for trusting and securely configuring their selected endpoints and for avoiding submission of sensitive content to services that should not receive it.

## Children's Privacy

OmniPilot is a general-purpose developer and productivity tool and is not directed to children under 13. The project does not knowingly collect personal information from children through an OmniPilot-operated service.

## Changes to This Policy

This policy may be updated when OmniPilot's behavior or legal obligations change. Updates will be published in this repository with a revised effective date.

## Contact

For privacy questions or requests concerning the OmniPilot project, open an issue in [OmniPilot GitHub Issues](https://github.com/OmniLLM/omni-pilot/issues). Do not include API keys, tokens, private prompts, or other sensitive information in a public issue.
